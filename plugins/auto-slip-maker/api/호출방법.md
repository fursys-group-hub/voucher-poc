# API 호출 방법 (공통)

> 지금은 개발서버(개발 DB)를 부른다. 인증 방식이 정해지면 바뀐다.

## 부르는 법

- 주소: 설정 파일의 `ACCOUNTAPI_URL` + 각 API 경로. 모두 `POST`, JSON, UTF-8
- 같은 폴더의 `call.py`로 부른다. 요청 `data`를 JSON 파일로 저장한 뒤 넘긴다 (한글이 깨지지 않게).
  ```
  python -X utf8 "$CLAUDE_PLUGIN_ROOT/api/call.py" slip/search 요청.json
  ```
  - API 경로는 `/api/account/v1/` 뒤 부분만 쓴다 (아래 목록의 "짧은 경로").
  - `$CLAUDE_PLUGIN_ROOT` 가 비어 있으면 `~/.claude/plugins/cache` 아래에서 `auto-slip-maker/<버전>/api/call.py` 를 찾는다.
  - 응답 JSON 전체를 화면에 출력한다.
  - 요청 파일은 작업 폴더에 두고 다 쓰면 지운다.
- 서버 주소, 인증키, 호출 식별자, 작성자 ID는 현업 PC의 설정 파일 `~/.auto-slip-maker/api.env` 에 있다 (환경변수가 있으면 그쪽이 먼저). 시작 단계에서 `setup.py`가 빈 칸으로 만들고, 현업이 메모장으로 채운다. `call.py`만 이 파일을 읽는다.
  - AI는 이 파일을 열거나 출력하지 않고, 값을 채팅·작업 폴더·명령에 쓰지 않는다.
  - `ACCOUNTAPI_URL`: 서버 주소. `call.py`가 각 API 경로 앞에 붙인다.
  - `ACCOUNTAPI_KEY`, `ACCOUNTAPI_IDENTIFIER`: `call.py`가 요청 본문에 넣는다.
  - `ACCOUNTAPI_USER_ID`: 작성자 ID. `user_id`가 필요한 API에 `"user_id": "$USER"`라고 쓰면 `call.py`가 이 값으로 바꾼다.
  - 설정이 없으면 `call.py`가 알려 주고 멈춘다. 그때는 `python -X utf8 "$CLAUDE_PLUGIN_ROOT/api/setup.py"`로 설정 파일을 열어 주고, 현업이 채워 저장하면 다시 부른다.
- `call.py`를 실행할 때마다 승인 창이 뜬다 (플러그인 훅 `hooks/ask_api.py`). 창에는 어떤 API를 어떤 조건으로 부르는지 나온다.
  - 현업이 승인하지 않으면 그 조회 없이 진행할지, 다른 조건으로 다시 부를지 현업에게 묻는다.

## 응답

- 성공: `{"_code": 200, "_message": "...", "data": {...}}`
- 실패: `_code`가 400·401·500이고 `_message`에 이유가 있다. 400이면 메시지를 읽고 요청을 고친다.
- 목록 API는 최대 50건이다. 더 있으면 `has_more`가 `true`이니 검색어를 좁힌다.
