# 코스트센터 조회 API

`POST /api/account/v1/costcenter/search` — 코스트센터를 손익센터·원가구분과 함께 조회한다. 부르는 법은 [호출방법.md](호출방법.md).

## 요청 (`data`)

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `company_code` | 필수 | 법인 코드. 코스트센터는 법인마다 다르다 |
| `keyword` | 조건부 | 코스트센터 코드나 이름 일부. 사용 중인 것만 나온다 |
| `cc_codes` | 조건부 | 코스트센터 코드 목록 (최대 50개). 사용 여부와 관계없이 나온다 |

- `keyword`와 `cc_codes` 중 하나만 보낸다.

## 응답 (`data.list[]`)

| 필드 | 설명 |
| --- | --- |
| `cd_cc`, `nm_cc` | 코스트센터 |
| `cd_pc`, `nm_pc` | 손익센터. 코스트센터를 따라 정해진다 |
| `fg_human_cc`, `nm_human_cc` | 원가구분. `A` (판) 판관비, `B` (제) 제조원가, `C` (용) 용역, `D` (공) 공통, `E` 영업외 |
| `yn_use` | 사용 여부. `N`이면 지금 쓰지 않는 코스트센터라고 알린다 |

- 판관비·제조원가 계정 중 무엇을 쓸지는 원가구분으로 알 수 있다 (`A`면 (판) 계정, `B`면 (제) 계정).
