# 계정과목 조회 API

`POST /api/account/v1/account/search` — 계정과 그 계정의 관리항목을 조회한다. 부르는 법은 [호출방법.md](호출방법.md).

## 요청 (`data`) — 둘 중 하나만

| 필드 | 설명 |
| --- | --- |
| `keyword` | 계정 코드나 이름 일부. 지금 현업이 쓸 수 있는 계정만 나온다 |
| `account_codes` | 계정 코드 목록 (최대 50개). 사용 여부와 관계없이 나온다 |

## 응답 (`data.list[]` 계정)

| 필드 | 설명 |
| --- | --- |
| `cd_account`, `nm_account` | 계정 |
| `usable` | 지금 현업 전표에 쓸 수 있는지. `false`면 그 계정은 쓸 수 없다고 알린다 |
| `yn_costcenter` | 코스트센터를 쓰는 계정인지 `Y`/`N` |
| `yn_foreign_amt` | 외화를 관리하는 계정인지 `Y`/`N` |
| `manage_items[]` | 관리항목 (전표등록 화면 순서) |

## 관리항목 (`manage_items[]`)

| 필드 | 설명 |
| --- | --- |
| `code`, `item_name` | 관리항목 코드와 이름 |
| `required_dr`, `required_cr` | 차변 줄 / 대변 줄일 때 꼭 넣어야 하는지 |
| `input_type` | 채우는 방법 (아래) |
| `data_type`, `max_length` | `text`일 때만. `data_type`이 `date`면 `yyyy-MM-dd` |

| `input_type` | 채우는 방법 |
| --- | --- |
| `select` | 목록에서 고른다. 관리항목 값 조회 API로 찾는다 |
| `text` | 직접 입력한다. 원천 데이터 파일·계산·고정으로 채운다 |
| `partner` | 거래처(A2)를 고르면 함께 정해진다 (은행·상대계좌). 따로 정하지 않는다 |
| `blocked` | 조회·입력하지 않는다 (신용카드번호 등) |
| `unsupported` | 아직 자동화로 채울 수 없다. 현업에게 알리고 "필요한 API"로 적는다 |
