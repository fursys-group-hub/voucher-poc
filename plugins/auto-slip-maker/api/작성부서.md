# 작성부서 조회 API

`POST /api/account/v1/dept/search` — 작성자가 전표를 쓸 수 있는 부서를 조회한다. 부르는 법은 [호출방법.md](호출방법.md).

## 요청 (`data`)

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `user_id` | 필수 | 작성자 ID. `"$USER"`로 쓴다 |
| `company_code` | 필수 | 법인 코드 |
| `keyword` | 선택 | 부서 코드나 이름 일부. 없으면 권한 있는 부서 전체 |

## 응답 (`data.list[]`)

`cd_dept`/`nm_dept` 부서, `cd_company` 법인, `cd_cc`/`nm_cc` 부서 기본 코스트센터, `cd_pc`/`nm_pc` 손익센터, `cd_reg_biz_area`/`nm_reg_biz_area` 신고사업장, `yn_use` 사용 여부

- 사용 중지 부서(`yn_use` = `N`)도 나온다. 고르면 알리고 다시 고르게 한다.
