# 관리항목 값 조회 API

`POST /api/account/v1/manage/value/search` — 계정의 관리항목에 넣을 값을 찾는다 (거래처, 증빙 구분 등). 부르는 법은 [호출방법.md](호출방법.md).

## 요청 (`data`)

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `company_code` | 필수 | 법인 코드 |
| `account_code` | 필수 | 계정 코드 |
| `manage_code` | 필수 | 관리항목 코드 (예: `A2`) |
| `keyword` | 선택 | 값의 코드나 이름 일부 |
| `value_codes` | 선택 | 값 코드 목록. 지난 전표 값이 지금도 있는지 확인할 때 쓴다. `keyword`와 함께 보내지 않는다 |
| `context` | 선택 | 같은 줄에서 이미 정한 관리항목 값. 예: `{"A9": "S"}` |

- 계정과목 조회 API의 `input_type`이 `select`인 관리항목만 조회된다. 나머지는 400과 함께 이유가 온다.
- 미지급금(일반) 계정의 거래처(A2)는 출납구분(A9)을 먼저 정하고 `context`에 넣어야 한다.

## 응답 (`data`)

`manage_code`, `item_name`, `has_more`, `list[]`

| `list[]` 필드 | 설명 |
| --- | --- |
| `value`, `name` | 값 코드와 이름 |
| `yn_use` | 사용 여부 |
| `biz_no` | 거래처 사업자번호 (있을 때만) |
| `fills[]` | 이 값을 고르면 함께 정해지는 관리항목 `{code, value, name}` (예: 거래처를 고르면 은행·상대계좌) |
| `warning` | 전표등록 화면이 확인 창을 띄우는 경우의 문구. 있으면 자동으로 고르지 말고 현업에게 확인받는다 |
