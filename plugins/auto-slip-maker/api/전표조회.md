# 전표 조회 API

`POST /api/account/v1/slip/search` — 작성자가 쓴 전표를 줄·관리항목과 함께 조회한다. 부르는 법은 [호출방법.md](호출방법.md).

## 요청 (`data`)

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `user_id` | 필수 | 작성자 ID. `"$USER"`로 쓴다 |
| `no_slip_serial` | 선택 | 전표번호. 보내면 이 전표만 조회 (기간·검색어 무시) |
| `keyword` | 선택 | 적요 검색어. 줄 적요 부분 일치, 공백 무시 |
| `from_dt`, `to_dt` | 선택 | 전표일자 기간 `yyyy-MM-dd`. 함께 보낸다. 없으면 최근 6개월, 최대 1년 |

- 이 작성자가 쓴 전표만 나온다. 전표일자 최신 순, 최대 50건.

## 응답 (`data.list[]` 전표 한 건)

| 구분 | 필드 |
| --- | --- |
| 전표 | `no_slip_serial` 전표번호, `cd_company`/`nm_company` 법인, `dt_slip` 전표일자, `cd_dept`/`nm_dept` 작성부서, `cd_path`/`nm_path` 전표유형, `yn_approve`/`nm_approve` 승인 상태 |
| 줄 (`detail_list[]`) | `seq` 순번, `cd_account`/`nm_account` 계정, `fg_drcr`/`nm_drcr` 차대(1 차변, 2 대변), `cd_cc`/`nm_cc` 코스트센터, `cd_pc`/`nm_pc` 손익센터, `unit_currency` 통화, `rate_exchange` 환율, `amt_account` 금액, `famt_account` 외화금액, `txt_remark` 적요 |
| 관리항목 (`manage_items[]`) | `code` 관리항목 코드, `item_name` 관리항목명, `value` 값, `name` 값의 이름 |
